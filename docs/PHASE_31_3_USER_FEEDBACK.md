## 1. Structured Feedback Collection Framework

During the operational pilot, real school users will submit structured qualitative and quantitative feedback across 4 primary stakeholder groups:

### A. School Administrator / Principal
- System overview dashboard clarity
- User onboarding and role management experience
- Academic and financial analytics usefulness
- Data export and report generation reliability

### B. Teachers & Faculty
- Daily roll-call attendance speed and simplicity
- Homework assignment dispatch and attachment handling
- Examination mark entry and calculation workflow
- Teacher Cockpit daily schedule visibility

### C. Accounts & Finance Staff
- Fee structure definition and assignment workflow
- Counter fee collection and receipt generation speed
- Reconciliation of daily collection reports

### D. Parents & Guardians
- Parent portal login and mobile browser responsiveness
- Multi-child switching and profile accuracy
- Attendance and homework visibility
- Report card viewing and fee payment transparency
